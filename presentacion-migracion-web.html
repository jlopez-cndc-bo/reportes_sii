Migración de los módulos de Indisponibilidades y SMEC a una aplicación web moderna, con acceso directo desde el navegador y la base Oracle en modo solo lectura.

SISTEMA EN PRODUCCIÓN 27 · 07 · 2026
Contexto

Un sistema que cumplió su ciclo

  • Escritorio, módulo por módulo — SMEC, Indisponibilidades y 04_DC_DATA son aplicaciones WinForms separadas que se instalan equipo por equipo.
  • Tecnología de más de 15 años — .NET 2.0/3.5, arquitectura de 32 bits, sin actualizaciones posibles del framework base.
  • Configuración manual por PC — la conexión a Oracle se define a mano en el Registro de Windows de cada estación de trabajo.
  • Cada cambio, una reinstalación — no existe una versión única: actualizar significa tocar cada equipo de la red.
Objetivo

Una sola aplicación, en el navegador

  • Acceso inmediato — desde cualquier PC de la red, sin instalar nada: solo un enlace.
  • Una única versión — se actualiza en el servidor una vez, no equipo por equipo.
  • Oracle en modo solo lectura — la aplicación web nunca escribe sobre las tablas productivas.
  • Base para el resto de módulos — el mismo backend queda listo para incorporar SCADA y SISFALLA a futuro.

Corto plazo

Datos SCADA, disponibles por API

Antes de reconstruir toda la pantalla visual de SCADA, el primer paso es exponer sus datos para que se puedan consultar directamente:

  • Consulta de potencia en tiempo real — los mismos datos que hoy solo se ven en la pantalla SCADA de escritorio
  • Acceso a los datos del HFD de SCADA — Generación, Transferencia, Embalses y TAP
  • Acceso mediante una API — una ruta estándar para que otros sistemas consulten esos datos, sin pasar por una pantalla
  • Uso interno dentro del CNDC — otras áreas y procesos internos podrán consumir esos datos para sus propias necesidades
¿Qué es una API?

Es una puerta de acceso estandarizada: un sistema pide datos con una solicitud simple — por ejemplo, "dame la potencia de la última hora" — y recibe la respuesta lista para usar.

Dentro del CNDC, otros procesos y sistemas internos podrán consumir esos datos de SCADA directamente para su propio trabajo, sin duplicar información ni depender de la pantalla de escritorio.

Indisponibilidades y SMEC funcionan de punta a punta en la nueva plataforma: verificados contra datos reales, desplegados con datos reales y en uso por todo el equipo.
